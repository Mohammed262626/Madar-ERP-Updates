# مدار ERP - نظام إدارة المخزون والمبيعات

نظام شامل ومتكامل لإدارة المخزون، المبيعات، الحسابات، والموارد البشرية. مبني بأحدث التقنيات ليوفر أداءً سريعاً وواجهة مستخدم عصرية وسهلة الاستخدام.

## 🌟 المميزات الرئيسية
- **إدارة المخزون:** تتبع دقيق للمنتجات، الفئات، ووحدات القياس.
- **إدارة المبيعات والمشتريات:** إنشاء فواتير احترافية ومتابعة الأرصدة.
- **نظام الحسابات والمالية:** تتبع الخزينة، الديون، وتسديد الدفعات.
- **إدارة الموظفين والصلاحيات:** تحكم كامل في صلاحيات المستخدمين.
- **تحديثات تلقائية:** نظام تحديث تلقائي مدمج (Auto-Updater) لنسخة سطح المكتب.
- **إشعارات Telegram:** نظام إشعارات فوري لتنبيه الإدارة بالعمليات الهامة.
- **نسخ احتياطي:** إمكانية أخذ نسخ احتياطية لقاعدة البيانات واستعادتها.

## 🛠️ التقنيات المستخدمة
- **الواجهة الأمامية (Frontend):** React, TypeScript, TailwindCSS, Vite
- **الواجهة الخلفية (Backend):** Node.js, Express
- **قاعدة البيانات (Database):** SQLite (node:sqlite) المدمجة
- **نسخة سطح المكتب (Desktop):** Electron, electron-builder, electron-updater
- **الدمج والبناء (Bundler):** esbuild (لدمج الخادم وتقليل حجم التطبيق)

## 🚀 كيفية التشغيل والتطوير

### المتطلبات المسبقة
- Node.js (الإصدار 22.5 أو أحدث لدعم `node:sqlite`)
- npm أو yarn

### التثبيت
\`\`\`bash
# تثبيت الحزم
npm install
\`\`\`

### بيئة التطوير (Development)
لتشغيل النظام في وضع التطوير (واجهة React + خادم API معاً):
\`\`\`bash
npm run dev
\`\`\`
سيفتح التطبيق على المتصفح عبر المنفذ `5173`.

### بناء نسخة الويب (Web Production)
\`\`\`bash
npm run build
npm run start
\`\`\`

### بناء نسخة سطح المكتب (Desktop App)
لبناء ملف التثبيت `.exe` الخاص بنظام Windows:
\`\`\`bash
# 1. بناء ملفات الويب والخادم أولاً
npm run build

# 2. بناء ملف التثبيت (.exe)
npm run electron-pack
\`\`\`
ستجد ملف التثبيت وملف `latest.yml` (الخاص بالتحديثات التلقائية) في مجلد `dist-electron`.

## 📦 كيفية رفع تحديث جديد
1. قم بزيادة رقم الإصدار في ملف `package.json`.
2. قم بتشغيل أمر البناء `npm run electron-pack`.
3. اذهب إلى مستودع GitHub الخاص بالتحديثات (Madar-ERP-Updates).
4. أنشئ إصداراً جديداً (Release).
5. قم برفع كل من `Madar ERP Setup X.X.X.exe` وَ `latest.yml`.
6. سيقوم التطبيق المثبت لدى العملاء باكتشاف التحديث وتحميله تلقائياً.
